## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

1. **Modular Monolith & Decoupling**: Does the architecture preserve high cohesion and low coupling within the monolith? Are cross-module communications governed strictly by explicit interfaces/contracts?
2. **Strict Static Typing**: Are all models, inputs, outputs, and interface contracts strictly typed without dynamic escapes (`any`, untyped dictionaries)?
3. **English-Only Codebase**: Are all module names, class/function identifiers, variables, comments, and documentation strictly in English?
4. **Clean & Minimalist Interface**: If introducing or modifying user-facing elements, does the design remain distraction-free, minimalist, responsive, and provide clear operational feedback?
5. **SOLID, Clean Code & DRY**: Does each component have a single responsibility? Are low-level dependencies inverted? Is domain logic deduplicated?
6. **Spec-Driven TDD**: Are all user story acceptance criteria backed by real automated tests (unit, contract, or integration) without fictitious mocks? Are tests planned to be written first?
